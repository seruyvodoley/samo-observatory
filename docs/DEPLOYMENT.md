# Размещение САМО

**Проверено 2 ноября 2026 года.** Основной публичный адрес — [samo-observatory.duckdns.org](https://samo-observatory.duckdns.org/). Сайт отдаёт read-only origin на VPS; актуальный снимок данных формирует отдельный экспортёр на том же VPS. Главная страница читает опубликованный снимок и не запускает вычисления.

## Что работает на VPS

- `samo-web.service` — статическая обсерватория.
- `samo-organism-v6.service` — действующий эксперимент `samo-ecology-v6-morphology`.
- На VPS также размещены регистратор и экспортёр научных снимков.
- Сайт и организм имеют отдельные службы и назначение. Сайт не управляет экспериментом.

TunnelDeck и его службы не входят в развёртывание сайта. Не меняйте их для обновления обсерватории.

Cloudflare Pages не является источником сайта и не используется для публикации изменений САМО. Не запускайте `wrangler` для этого проекта. Публичный адрес Cloudflare, если он ещё открывается, может показывать сохранённую старую копию; ориентируйтесь на DuckDNS и отметку времени в обсерватории.

## Безопасное обновление сайта

Для публикации используется отдельный системный аккаунт `samo-deploy` и отдельный SSH-ключ. Ключ ограничен принудительной командой `rrsync`: он может загружать только статические файлы в `/srv/samo/site`, не может удалять файлы, открывать shell или менять научные данные. Каталог `/srv/samo/site/data` принадлежит экспортёру и недоступен этому аккаунту для записи. Административный ключ TunnelDeck не используется для публикаций.

На компьютере адрес хранится только в `~/.ssh/config` под псевдонимом `samo-vps-deploy`; частный адрес и ключ не добавляются в репозиторий. Для публикации используются текущие настроенные ключ и псевдоним:

```sh
npm run build --prefix web
python3 tools/deploy_vps.py --host samo-vps-deploy --identity ~/.ssh/samo_vps_deploy_ed25519
```

Псевдоним доступен при активном соединении TunnelDeck. Ключ хранится на локальном компьютере и не должен передаваться в Git, документацию, снимки экрана или публичную сборку.

Эксперимент и экспортёр обновляют `/data/ecosystem.json` независимо от сборки сайта. Не заменяйте этот файл локальным снимком при публикации интерфейса. Проверяйте публичную отметку времени, протокол и номер попытки после изменений.

## Ресурсные пределы

Проект рассчитан на утверждённые пределы: организм — до 40% одного логического CPU и 512 000 000 байт RAM без swap; все службы — до 768 000 000 байт RAM; диск проекта — до 1 000 000 000 байт. Эти значения должны подтверждаться фактической конфигурацией и измерениями на VPS, а не только файлами проекта.

Публичное наблюдение и вычислительная эволюция — разные процессы. Работа сайта не означает, что найдена новая способность; научный результат требует отдельного независимого испытания.
