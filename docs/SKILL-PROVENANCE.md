# Provenance проекта

Проверенные Agent Skills установлены в `.agents/skills/`, чтобы Codex мог загружать их как проектные инструкции. Список файлов и контрольные суммы отдельных `SKILL.md` находятся в [`skills-lock.json`](../skills-lock.json). Установщик: `skills@1.7.4`, режим проекта, агент `codex`.

| Назначение | Источник | Зафиксированный исходник |
|---|---|---|
| Дизайн, сборка и браузерная проверка интерфейса | `openai/plugins` · `build-web-apps` | `0722921d5542fc593105c27bd52630babd8b8c2a` |
| GSAP: основы, React, плагины, таймлайны, ScrollTrigger и скорость | `greensock/gsap-skills` | `aed9cfd3277740755f6bfc1155c7aa645403b760` |
| GSAP и переходы React Router | `johnpolacek/animaxxing-skills` | `8ddf542ec239b018ba43ce0878842205c529b1c6` |
| Three.js: сцена, геометрия, анимация, доступность, тестирование и скорость | `cesartevisual/threejs-skills` · MIT | `84f9bcb4bea1f7a28d57fe7f0af78f7f9c3dc467` |
| Инженерия эволюции, методология исследования, дизайн обсерватории и изоляция | локальные проектные инструкции | `.agents/skills/samo-*` |

## Проверка до установки

- Проверены репозитории, пути выбранных навыков и точные файлы `SKILL.md` на указанных ревизиях.
- Сторонние файлы навыков — текстовые инструкции; исполняемые установочные хуки и неизвестные команды не запускались.
- GSAP и Animaxxing отобраны как официальные/авторские источники проектов. Навыки Three.js взяты из отдельного MIT-репозитория сообщества, а не названы официальными навыками Three.js.
- Установщик сообщил `Safe`, ноль предупреждений безопасности и ноль уязвимостей для выбранных источников.
- Для WebGL не ставился OGL-специфичный навык и не добавлялись собственные шейдеры: сцену напрямую обслуживает Three.js.

## Изменения в проекте

Использованы направления и ограничения навыков: единый renderer, стабильные IDs, локальная камера, пассивные слушатели прокрутки, `prefers-reduced-motion`, сохранение доступной HTML-альтернативы и ручное освобождение GPU-ресурсов. Навыки не являются источником научных данных и не меняют критерии эксперимента.
