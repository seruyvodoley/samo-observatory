## Популяционный runtime v2 — 31 октября 2026

САМО работает на VPS: популяционный runner, SQLite-регистратор и независимые экспорт/публикация. Публичная обсерватория: [открыть сайт](https://samo-observatory.duckdns.org/). Новые лимиты: организм 512 000 000 байт RAM, весь slice 768 000 000 байт, проектный диск до 1 000 000 000 байт. Подробные реальные значения, испытания, инцидент SQLite и ограничения: [OPERATIONS.md](OPERATIONS.md). Ниже сохранена документация предыдущих стадий; старые статусы «не запущено» относятся к ним.

# Архитектура САМО 0.1

Python 3.9+ без runtime-зависимостей: целочисленная стековая VM, эволюционное ядро, независимый испытатель, SQLite-регистратор, валидирующий статический экспортёр. React + TypeScript + React Router + Vite: публичный read-only клиент. SQLite выбран ради транзакций и малого footprint; UI не содержит экспериментальных API. Библиотеки сайта фиксируются lockfile. Никакого LLM внутри эксперимента.

Изменяемый геном: несколько предсказывающих программ, программа маршрутизации, исполняемый оператор поиска, семантические программы четырёх пользовательских инструкций, наследуемая память. Внешние инструкции VM, декодер правок, evaluator, selection и лимиты неизменяемы. Это ограниченная модель самоизменения: не произвольная модификация Python-ядра или внешнего отбора.

Оператор поиска исполняется в той же VM и выводит последовательность четверок (цель, адрес, вид правки, значение). Потомок наследует изменённый оператор и реально применяет его при следующем размножении. Правки вставляют, удаляют и заменяют инструкции, память, модули и семантику. Программа может потерять способность размножаться. Синтаксически допустимый потомок может быть бесполезен. Metropolis допускает снижение качества, архивный рекорд никогда не возвращается в активную память.

Пользовательские инструкции вызывают наследуемые программы над входным стеком; CALL запрещён внутри семантики, чтобы глубина была конечна. Это исполняемый путь изменения представления, не доказательство спонтанного возникновения языка. Операции 16-битные; ограничены стек, память, длины, вывод, общий fuel и wall deadline. Геном не имеет инструкций файлов, сети, Python eval/exec, импортов или запуска процессов.

Испытатель генерирует train, validation, confirm и transfer независимыми приватными seed. Предсказание вычисляется из префикса, затем сохраняется commitment, затем раскрывается правильное значение. Поиск получает только train score. Источники задач/ответы/seed никогда не являются VM context. VM — capability boundary, а не отдельная OS VM: баг доверенного Python может нарушить её. На macOS пилот запускается без утверждения о Linux-изоляции.

Регистратор хранит каждый кандидат, отрицательные исходы, родителей, PRNG, хеши генома/семантики/поиска/памяти, затраты и сырые испытания. Он не доступен VM. Лимит архива 64 MB с остановкой сбора, без удаления неудач. Экспортёр читает завершённые транзакции, проверяет связи, hashes, размер, DAG и схему. Снимок ограничен 4 MB; последний полный снимок заменяется атомарно. Сайт читает только эту копию и продолжает работать после остановки эксперимента.

Долгий запуск — локальный supervisor с паузами между ограниченными работами, не веб-таймер и не посещения сайта. Состояние текущего организма/PRNG коммитится в каждой записи. Восстановление — точное продолжение, а не откат к лучшему. Для продакшна обязательна отдельная Linux VM-приёмка изоляции; конфигурации deploy являются непроверенными шаблонами.
# Экосистема: экспериментальный слой

`samo/ecosystem.py` — локальный прототип популяционной модели поверх того же ограниченного VM/genome API. Он добавляет популяцию до восьми активных организмов, двух родителей, кроссовер модулей/router/search/dialect/memory, стохастический отбор с возможностью регрессий, детерминированный counter-based поток задач и явное событие `recolonization` для отдельного эпизода после вымирания. Стерильная особь умирает после трёх неудачных попыток; экосистема не оценивается по числу эпизодов.

Контрольная точка сохраняет PRNG, популяцию, bounded diversity archive и журнал событий атомарным JSON. Ресурсные пределы сегмента — максимум 512 геномов, 12 000 событий, checkpoint 48 МБ; при заполнении запись прекращается с ошибкой, история не прореживается. Задачи продолжаются по индексу, каждая имеет независимо выводимый seed и сохраняется в событии. Добавление семейств или изменение отбора требует новой версии протокола.

Это пока исследовательский модуль, а не замена production `watch`: он не подключён к SQLite exporter, systemd supervisor, публичной схеме snapshot и долгосрочному Linux soak. Следовательно, пока нельзя заявлять непрерывную многолетнюю работу всей экосистемы или публичную видимость её событий. Протокол [`ecosystem-v1.json`](../protocols/ecosystem-v1.json) фиксирует ограничения и статус.
