# Исправление связей родословной

Дата: 3 ноября 2026 года.

## Причина

Основной снимок обсерватории сохраняет подробные данные только для последних восьми исторических форм и текущей популяции. Для дерева этого недостаточно: записи потомков ссылались на родителей, которых снимок не включал. У некоторых записей также различались отображаемый идентификатор `@birth-…` и постоянный `organism_id`.

## Изменение

- Граф сопоставляет формы по постоянному идентификатору организма и не рисует несколько точек для одного организма.
- Отдельная служба только для чтения извлекает из регистратора предков выбранной части родословной. Она публикует до 160 подробных форм, сжимает сохранённую геометрию и ограничивает файл 3 800 000 байтами.
- Снимок родословной обновляется отдельным systemd-таймером раз в минуту. Основной снимок организма и вычислительная база не меняются.
- Если предок отсутствует в сохранившемся диапазоне или превышен лимит выгрузки, связь остаётся отмеченной как отсутствующий архивный родитель. Фиктивные линии не добавляются.

## Проверка на VPS

На проверенном снимке v7 экспортёр восстановил 65 форм и 84 родительские связи; все ссылки внутри доступного регистратора разрешились. Файл выгрузки занял около 0,44 МБ. Контрольная сумма снимка совпала. Служба экспортёра ограничена 10% CPU и 128 000 000 байт RAM; она работает в общем `samo.slice` и не имеет доступа на запись к базе.

После проверки в браузере выявилась несовместимость способа расчёта контрольной суммы: Python и JavaScript по-разному представляли некоторые числа при повторной сериализации. Архив переделан так, чтобы проверялась точная сохранённая строка данных, а не её повторно собранный объект. На публичном снимке шага 490 браузер загрузил 89 форм и построил 115 родительских связей; неразрешённых родителей — 0, корневых форм — 2, архив не усечён. Публичная страница показала обновлённое число сохранённых форм.

Также исправлено поведение просмотра пустой части программы: раньше выбор пустого модуля оставлял увеличенный вид наследуемой формы, поскольку у её декоративных узлов всё ещё было соответствующее обозначение модуля. Теперь такой выбор возвращает полный вид; текст «Показываем программу целиком» соответствует изображению. Проверено на публичной странице программ в Chromium.

Изменение касается отображения и экспорта родословной. Протокол поиска, популяция и результаты вычислительной эволюции не изменялись.
