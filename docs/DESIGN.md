# Художественное направление

Обсерватория как журнал измерительного прибора: глубокий сине-серый фон #11191e, поверхность #18252b, свет бумаги #e3e8e5, холодная линия #91c9cb, латунь #d2b879, сигнал потери #e49c91. Цвет кодирует принятие, отклонение и регрессию, но всегда сопровождается текстом/формой. Без внешних шрифтов: Charter/Georgia для крупных русских заголовков, system sans для навигации и текста, системный mono только для байткода и чисел.

Главная: спокойная общая навигация; слева название состояния и контекст остановки; справа «срез программы» — концентрические дорожки реальных инструкций текущего генома. Каждая дуга означает инструкцию, кольцо — конкретную подсистему. Данные, а не декоративная нейросеть. Ниже — график реальных оценок и последние изменения; ресурсный бюджет линейный, не сетка KPI. В подробном организме тот же срез остаётся пространственным якорем, рядом раскрываются код и зависимости.

Проверка против шаблона: убраны маркетинговый hero, одинаковые карточки и вечный пульс «живого» организма. Состояние остановки занимает заметное место. Самая выразительная часть — графическое представление артефакта; остальные элементы поддерживают чтение доказательств. Граф родословной на мобильном заменяется доступным хронологическим списком с родителями, а не сжимается до нечитаемости.

Переходы: View Transitions при поддержке браузером, общий каркас, мягкое перекрытие страницы и именованный общий specimen. Fallback CSS entrance; reduced-motion выключает оба механизма. URL сохраняет запуск, фильтры и историческое сравнение. Ошибочный идентификатор не заменяется текущим организмом.
